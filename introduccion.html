Nuestra Filosofía

"La tecnología es el lenguaje, pero la comunicación asertiva es lo que permite que el software resuelva problemas reales."

Como equipo, entendemos la comunicación como el proceso de asegurar que todos estemos exactamente en la misma página y que el mensaje realmente se entienda, no solo que se transmita.

En nuestro campo, el desarrollo de software, esto es el doble de importante. Nos hemos dado cuenta de que de nada sirve que sepamos tirar código limpio o estructurar bases de datos robustas si a la hora de la verdad no sabemos escuchar lo que el cliente necesita, o si nos cuesta explicarnos entre nosotros dentro del equipo.

Una mala comunicación rompe la lógica de cualquier proyecto y genera reprocesos innecesarios. Por eso, para nosotros, aprender a comunicarnos bien ha sido tan vital como aprender a programar: es lo que nos permite conectar el código con las necesidades de las personas reales.
